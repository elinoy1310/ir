## שלב 0 – עיבוד מקדים: הפרדת פיסוק ולמטיזציה  

**מטרה:** לאחד את סגנון הטקסטים ולהקטין וריאציות לשוניות לפני בניית הייצוגים.  

**ביצוע (stage_0_preprocess.py):**  
- קלט: קבצי `.txt` בתיקיות `UK` ו־`US`.  
- הפרדת סימני פיסוק בעזרת `string.punctuation` והוספת רווח לפני ואחרי כל סימן → שמירה בתיקיות `tokens/UK`, `tokens/US`.  
- הרצת מודל `spaCy (en_core_web_sm)` על הטקסט עם הפיסוק המופרד, המרת כל טוקן ללמה (צורת בסיס), והשמטת רווחים → שמירה בתיקיות `lemmas/UK`, `lemmas/US`.  

**תוצאה:** 689 מסמכים מלומטים ונקיים, זהים במספר למסמכי המקור אך עם טקסט אחיד יותר לעיבוד.

---

## שלב 1 – טעינת מסמכים מלומטים  

**מטרה:** ליצור מבנה נתונים אחיד של טקסט + תווית + שם קובץ.  

**ביצוע (stage_0_load.py):**  
- קריאה מקבצי `lemmas/UK` ו־`lemmas/US`.  
- לכל קובץ נשמרים:  
  - הטקסט המלומט (`texts`),  
  - התווית המתאימה: UK=0, US=1 (`labels`),  
  - שם הקובץ (`filenames`).  

**תוצאה:**  
- נטענו 689 מסמכים (≈329 UK, ≈360 US).  
- שלוש רשימות מקבילות באותו אורך המשמשות כבסיס לכל השלבים הבאים.

## שלב 2 – בניית ייצוג TF-IDF אחיד למסמכי UK+US  

**מטרה:** להמיר את המסמכים למטריצה מספרית אחת שתשמש לכל אלגוריתמי ה־Clustering והסיווג.  

**ביצוע (stage_1_tfidf.py):**  
- שימוש ב־`TfidfVectorizer` עם:  
  - `max_features=5000` – עד 5000 מונחים משמעותיים,  
  - `stop_words="english"` – סינון stopwords.  
- התאמת ה־Vectorizer לכל המסמכים המלומטים וחישוב מטריצת TF-IDF.  

**תוצאה:**  
- התקבלה מטריצה דלילה בגודל **689 × 5000**.  
- כל שורה = מסמך (UK או US), כל עמודה = מונח, כל תא = משקל TF-IDF של המונח במסמך.

## שלב 3 – KMeans על TF-IDF  

**מטרה:** לבדוק האם ניתן להפריד בין UK ל־US בעזרת אשכול לא־מפוקח פשוט.  

**ביצוע (stage_2_kmeans.py):**  
- המרת המטריצה ל־dense (`toarray`).  
- הרצת `KMeans` עם `n_clusters=2`, `random_state=42`, `n_init=10`.  
- בדיקה מי מבין {אשכול 0, אשכול 1} מתאים ל־UK/US ע"י השוואה לתוויות והיפוך במידת הצורך.  

**תוצאות:**  
- **Confusion matrix:**  
  `[[329   0], [  0 360]]`  
- **Accuracy = 1.0, Precision = 1.0, Recall = 1.0, F1 = 1.0**  

**מסקנה:** גם ללא שימוש בתוויות בזמן האשכול, KMeans מצליח לשחזר באופן מושלם את ההפרדה בין מסמכי UK למסמכי US על בסיס TF-IDF של למות.

## שלב 4 – DBSCAN על TF-IDF (Cosine Distance)  

**מטרה:** לאתר אשכולות טבעיים ללא הנחה מראש על מספר האשכולות, תוך התחשבות בצפיפות המקומית של המסמכים.  

**ביצוע (stage_3_dbscan.py):**  
- חישוב מטריצת **cosine distance** לכל זוג מסמכים.  
- הרצת `DBSCAN` עם `metric="precomputed"`, `eps=0.45`, `min_samples=5`.  
- התעלמות מנקודות שסומנו כרעש (`label=-1`) ומיפוי אשכולות ל־0/1 לפי רוב המסמכים באשכול.  

**תוצאות:**  
- **Total points:** 689  
- **Noise points:** 50  
- **Confusion matrix (ללא רעש):**  
  `[[308   0], [  0 331]]`  
- **Accuracy = Precision = Recall = F1 = 1.0**  

**מסקנה:** DBSCAN מאתר שתי קבוצות צפופות המתאימות בדיוק ל־UK ול־US. מספר קטן של מסמכים (50) מסומנים כרעש – נאומים חריגים או קצרים במיוחד.

- **Cluster sizes:** {0: 322, 1: 357}  
- **Confusion matrix (ללא רעש):**  
  `[[322   0], [  0 357]]`

**מסקנה:** HDBSCAN מצליח למצוא שתי קבוצות יציבות מאוד, עם פחות רעש מ־DBSCAN ותאימות מלאה לחלוקה UK/US.

**תוצאות:**  
- **Cluster sizes:** {0: 329, 1: 360}  
- **Confusion matrix:**  
  `[[329   0], [  0 360]]`  
- **Accuracy = Precision = Recall = F1 = 1.0**  

**מסקנה:** גם לאחר הורדת מימד, GMM מזהה שתי התפלגויות גאוסיות נפרדות המתאימות לחלוקה UK/US באופן מושלם.
